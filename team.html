为什么需要一个组队插件

在多人服里，"一起玩"这件事其实很难落地：谁和谁一队、队友之间能不能互相打到、 怎么在公共聊天里说一句只给队友看的话 —— 这些东西原版一个都没有。

LinuxTeam 把这些补上：一块 GUI 面板管住成员、设置与队标， 一个聊天频道让队友单独说话， 一层免误伤让团战不再互相打断， 再顺手把 疯狂附魔 的效果接进队伍里。

  • 不用记命令
    输入 /team 打开面板，点图标就能做完所有事
  • 队友打不到你
    同队成员之间的伤害默认关闭，范围伤害也不会误伤
  • 队伍有自己的频道
    开启后你打的字只发给队友，公共频道看不到
FEATURES

核心功能

队伍管理、聊天、战斗保护与附魔联动

🗂️

GUI 管理面板

整支队伍的操作都收在一块箱子界面里，不需要背命令。

  • 创建 / 邀请 / 加入 / 踢出 / 解散一站完成
  • 成员卡片显示在线状态与入队时间，右键可转交队长
  • 队伍设置里可开关队友伤害与队伍聊天
  • 浏览列表能看到全服所有队伍与在线人数
💬

队伍聊天频道

用 /team chat 切换频道，之后你打的字只发给队友。

  • 公共频道里完全看不到队伍消息
  • 退出 / 被踢 / 队伍解散时自动关闭频道并提示
  • 单发一条用 /tc <内容>，不切换频道
  • 管理员可用 /team spy 查看队伍聊天
🛡️

队友免误伤

同队成员之间的伤害默认关闭，团战不再互相打断。

  • 近战、弓箭、投掷物、药水全部覆盖
  • 队长可在设置里放开队友伤害
  • 拦截时只给攻击者一条提示，不刷屏
🏷️

头顶队标

队伍标记直接显示在名字前面，一眼看出谁和谁一组。

  • /team tag <标记> 设置，支持颜色代码
  • 改完立刻刷新，不需要重新上线
  • 字符有白名单，防止伪造管理员前缀
⚔️

疯狂附魔联动

把 CrazyEnchantments 的附魔效果接进队伍体系，队友之间互相增益。

  • 队伍加成：同队在线人数越多，附魔触发概率越高
  • 附魔共享：触发共享类附魔时，附近队友同步吃到增益
  • 附魔免误伤：进攻类附魔打到队友身上直接取消
🔧

申请制入队

默认不再"谁都能进" —— 玩家提交申请，由队长批准。

  • 退掉自己队伍就能潜入敌对队伍的口子已经堵上
  • 队长用 /team accept <玩家> 放行
  • 服主可在配置里改回"公开加入"模式
🔗

与其它插件配合

本插件默认与服务器上的其它自研插件共用同一套信息。

  • PlaceholderAPI：%linuxtream_team% 等 14 个变量， 可用于 TAB、记分板、聊天格式
  • Vault：可配置创建队伍收费
  • InTheNameOfLinux：/linux team 直接读取队伍信息， 封禁与举报界面会显示玩家所属队伍
  • LuckPerms：全部功能按权限节点控制
CRAZY ENCHANTMENTS

疯狂附魔联动怎么算

三项能力，各自可单独开关

📈

队伍加成

每多一名在附近的队友，附魔触发概率就高一点，有上限。

  • 默认每名队友 +15%，最多 +60%
  • 只统计 32 格内的队友（距离可配置，0 = 不限）
  • 可配白名单 / 黑名单指定哪些附魔吃加成
✨

附魔共享

触发共享类附魔时，把对应的增益效果同步给附近队友。

  • 默认覆盖 9 种附魔：吸血 / 生命窃取 / 祝福 / 恢复 …
  • 队友拿到的是缩放版：时长 ×0.8，等级可降
  • 3 秒冷却，避免连击时刷屏
🚫

附魔免误伤

进攻类附魔打到队友身上时直接取消，不会因为附魔效果伤到队友。

  • 与队友免误伤共用一套判定
  • 范围类附魔同样处理
  • 面板里有独立的联动说明页
队伍附魔 · 共享示意
  • 你 触发 吸血，周围有 3 名队友
  • 加成 触发概率 +45%（3 × 15%，未超上限）
  • 共享 附近队友获得 生命恢复，时长 ×0.8
  • 拦截 该附魔打到队友 → 伤害被取消
数值全部来自 config.yml → crazy-enchantments，可随时调整。
COMMANDS

命令一览

主命令 /team，简写 /lt，不带参数直接开面板

命令说明权限
/team打开 GUI 管理面板（不带参数即可）所有人
/team create <队名>创建一支队伍，自己成为队长所有人
/team invite <玩家>邀请玩家入队（默认 60 秒有效）所有人
/team join <队名>提交入队申请，由队长批准所有人
/team accept接受别人发来的邀请所有人
/team accept <玩家>队长批准某人的入队申请队长
/team kick <玩家>把成员移出队伍（被踢者频道自动关闭）队长
/team transfer <玩家>把队长转交给指定成员队长
/team tag <标记>设置头顶队标（支持颜色代码，留空清除）队长
/team leave退出当前队伍所有人
/team disband解散队伍（15 秒内再输一次确认）队长
/team list列出服务器上的所有队伍所有人
/team info [队名]查看队伍详情（不填则看自己的）所有人
/team chat开关队伍聊天频道所有人
/tc <内容>单发一条队伍消息（不切换频道）所有人
/team spy偷看全服队伍聊天OP
/team reload重载配置与队伍数据OP
