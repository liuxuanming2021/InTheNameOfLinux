FakePlayerPlugin

在服务器里放置不会掉线的"假玩家"

使用帮助 ← 插件列表 综合帮助
FEATURES

核心功能

创建、管理、持久化与兼容性

👥

创建假人

一条命令即可在当前位置生成一个假玩家。

  • /fp <名字> 在脚下创建
  • 假人有皮肤、会站在原地看着你
  • 可作为占位、装饰或活跃度展示
  • 创建者会被记录，便于追责
🧹

管理与移除

列出、移除单个或一键清空全部假人。

  • /fplist 列出全部假人
  • /fpr <名字> 移除指定假人
  • /fpr all 移除全部假人
  • 移除后立即从服务器消失
💾

数据持久化

假人配置存盘，服务器重启后自动恢复。

  • 假人数据写入配置文件
  • /fpsave 手动保存
  • 启动后分三次延迟加载，避免与其它插件抢时序
  • 假人不会因为重启消失
🧱

区块保护

强制加载假人所在区块，防止掉进虚空。

  • 自动强制加载所在区块
  • 区块卸载 / 世界卸载时自动处理
  • 定期自检并修复异常假人
  • 玩家传送后重新定位
🔐

AuthMe 兼容

不会因为登录验证被踢下线。

  • 兼容 AuthMe 的登录检查
  • 假人不参与登录验证流程
  • 避免被其他登录插件误判
  • 可与其它插件共存
🛠️

仅 OP 可用

所有命令都只对管理员开放，普通玩家无法创建。

  • 命令默认需要 OP 权限
  • 防止玩家刷假人占位
  • /fpreload 热重载配置
  • 帮助菜单列出全部可用命令
COMMANDS

命令一览

主命令 /fakeplayer，简写 /fp

命令说明权限
/fp显示插件信息OP
/fp <名字>在当前位置创建一个假人OP
/fp help显示帮助菜单OP
/fplist列出所有假人OP
/fpr <名字|all>移除指定假人，或移除全部OP
/fpreload重载插件配置OP
/fpsave手动保存假人数据OP
⚠️
命令别名 每个命令都有简写：/fp、/fplist（或 /fpl）、 /fpr、/fpreload、/fpsave。
