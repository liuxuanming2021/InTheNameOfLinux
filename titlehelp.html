1快速开始

LinuxTitle 是一个自动解锁的头衔插件：玩家不需要申请， 只要满足条件就会自动获得对应头衔。获得后可以自由切换显示或关闭。

三步上手

  1. 把 LinuxTitle.jar 放入 plugins/ 目录并重启服务器。
  2. 编辑 plugins/LinuxTitle/titles.yml，按需调整头衔名称与解锁条件。
  3. 执行 /title reload 让配置生效，玩家即可用 /title list 查看头衔。
💡
可选依赖 装了 PlaceholderAPI 的话，头衔可以用于其它插件的变量显示； 没装也能正常运行，只是变量不可用。

2命令详解

玩家命令

命令说明权限
/title help [页码]显示帮助菜单，按身份展示不同目录，可点击翻页所有人
/title list [页码]列出全部头衔，并标出自己哪些已解锁所有人
/title use <头衔ID>使用指定头衔（必须是已解锁的）所有人
/title off关闭头衔显示所有人
/title info <头衔ID>查看某个头衔的解锁条件与说明所有人

管理员命令

命令说明权限
/title give <玩家> <头衔ID>手动授予玩家头衔（无视解锁条件）linuxtitle.admin
/title revoke <玩家> <头衔ID>收回玩家已获得的头衔linuxtitle.admin
/title check [玩家]立即复查解锁条件（不填玩家则查全体在线）linuxtitle.admin
/title reload重载 config.yml 与 titles.ymllinuxtitle.admin
💡
命令别名 /title 也可以用 /titles 或 /lt 代替，效果完全相同。

3解锁条件

头衔按 解锁方式 分为六类，全部配置在 titles.yml 里。

解锁类型判定依据例子
first_join首次进入服务器新人
playtime累计游玩时长达到阈值常驻 / 元老
statistic某项原版统计达标（击杀 / 挖掘 / 死亡等）PVP 之王 / 矿工
daily_playtime当日在线时长达到阈值每日活跃 / 每日传奇
festival处于指定节日期间春节 / 中秋
manual只能由管理员 /title give 授予赞助者 / 自定义头衔

怎么改解锁阈值

打开 plugins/LinuxTitle/titles.yml，找到对应头衔，修改 condition-value 即可。例如把「常驻」改成需要 10 小时：

resident:
name: "&a常驻"
type: playtime
condition-value: 36000000 # 毫秒，10 小时

改完执行 /title reload 生效。时长一律用毫秒， 3600000 = 1 小时。

4节日活动

插件内置农历换算，春节、端午、中秋会按当年农历日期自动开放， 不需要每年手动改日期。

节日类型默认时间持续
元旦公历12-30 ~ 01-02跨年
春节农历正月初一10 天
端午节农历五月初五6 天
中秋节农历八月十五6 天
国庆节公历09-30 ~ 10-078 天
# 农历节日：填农历月、日，插件自动换算当年公历日期
spring_festival:
name: "春节"
type: "lunar"
lunar-month: 1
lunar-day: 1
duration: 10 # 持续天数（含开始当天）
# 公历节日：直接填 MM-dd
national_day:
name: "国庆节"
type: "solar"
start: "09-30"
end: "10-07"

5配置说明

config.yml 主要配置项

配置项默认值说明
allow-self-switchtrue是否允许玩家自己切换头衔。关掉后只能由管理员授予与指定。
allow-self-disabletrue是否允许玩家用 /title off 关闭头衔显示。
auto-check-interval-seconds60自动复查解锁条件的间隔（秒）。调小会更及时，但更耗性能。
help.modeauto帮助菜单的身份判定：auto 自动 / admin 一律管理员视角 / player 一律玩家视角。
chat.enabledtrue是否在聊天里显示头衔前缀。
daily.enabledtrue是否启用每日头衔（每天重新统计）。
daily.reset-hour / reset-minute0 / 0每日头衔的重置时间，默认每天 0 点。
newcomer.enabledtrue新玩家首次进服是否自动授予「新人」头衔。
newcomer.title-idnewcomer新人头衔的 ID。
newcomer.delay-seconds10进服后延迟几秒授予，避免与其它登录插件抢时序。
newcomer.max-playtime-millis3600000累计游玩超过这个时长就不再算新人（默认 1 小时）。
💡
关于 help.mode linuxtitle.admin 的默认值是 op，也就是说服里的 OP 会自动通过这个判定， 与他是不是"管理员"其实无关。如果你只是加了 OP、并不想看到管理员目录， 把 help.mode 设为 player 即可。

6权限节点

权限节点说明默认
linuxtitle.use玩家命令：list / use / info / off所有人
linuxtitle.admin管理命令：give / revoke / check / reloadOP
⚠️
只想给管理员、不想给全部 OP？ 在权限插件里把 linuxtitle.admin 显式授予指定玩家组， 同时不要给 -linuxtitle.admin 以外的 OP 默认权限（默认值改为 false）。

7常见问题

玩家说"我达到条件了但没解锁"？
先让玩家重进一次服务器，或执行 /title check <玩家> 立即复查。 若仍未解锁，用 /title info <头衔ID> 看条件是否与预期一致 （特别注意时长的单位是毫秒）。
头衔没有显示在聊天里？
依次检查：config.yml 的 chat.enabled 是否为 true； 玩家是否用 /title off 关掉了显示；确认玩家确实已经 /title use 了某个头衔。
我不是管理员，为什么 /title help 显示管理员目录？
因为 linuxtitle.admin 的默认值是 op，只要你是 OP 就会通过判定。 把 config.yml 的 help.mode 改成 player 可以强制按玩家视角显示。
每日头衔第二天还在？
每日头衔会在 daily.reset-hour / reset-minute 指定的时间重新统计。 如果没重置，检查 daily.enabled 是否为 true，以及服务器时间是否正确。
节日头衔日期不对？
农历节日由插件自动换算，一般不需要手动改。若确实需要固定日期， 把 type 从 lunar 改成 solar， 再用 start / end 指定 MM-dd。
改了配置怎么生效？
执行 /title reload。玩家已获得的头衔不会因为重载丢失。
