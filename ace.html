为什么是「宁可漏报」

反作弊最难的不是抓作弊，而是不冤枉正常玩家。 大多数反作弊装上去第一周，玩家投诉的往往是「我什么都没干就被踢了」。

LinuxACE 的取舍很明确：先保证不误报。 每次检测命中只累加一个「缓冲」，达到容忍次数才真正记一次违规； 缓冲每秒自动衰减，偶发一次永远不会积累成误判。

真正确认之后才加「危险等级」，攒到 20 才踢出，而且不封禁 —— 封不封人由 OP 自己判断。

  • 缓冲 + 容忍
    连续命中 3~6 次才算一次违规
  • 缓冲每秒衰减
    偶发一次永远不累计
  • 风险 45 秒衰减
    长期在线不会被无故踢
  • 豁免窗口
    传送/击退/重生后 2~4 秒不查
  • 卡服保护
    TPS 低于 15 整体暂停
  • 永不自动封禁
    只踢出，封禁由 OP 决定

OP 实时告警 · 点一下就飞过去

作弊发生时立刻广播给在线 OP，告警是可点击的。

  • 格式：[LinuxACE]玩家 X 触发了 Y，等级 N
  • 点「点击前往」→ 你变旁观者并传送到他身边
  • 鼠标悬停显示：世界 · 坐标 · 延迟 · TPS · 危险等级
  • /ace back 一键返回原位置与模式

  • Lowest / Low / Medium / Pro / High / Max / Highest

  • 同时调整阈值倍率与容忍倍率

COMMANDS

命令一览

全部通过 /ace，别名 /linuxace、/ac

命令作用
/ace打开反作弊主菜单（面板，只显示重要信息）
/ace help [页码]完整命令帮助，可分页、可点击
/ace status运行状态：强度、TPS、已关闭的检查、兼容插件
/ace checks列出全部检测项的开关、风险权重、容忍次数
/ace goto <玩家>变成旁观者并传送过去（告警里的「点击前往」）
/ace back返回观察前的位置与游戏模式
/ace check <玩家>查看某人的危险等级与各检查命中次数
/ace ban <玩家> [理由]手动封禁；不写理由时自动用检测记录生成
/ace exempt <玩家>临时豁免该玩家的检测
/ace reset <玩家>清零危险等级
/ace strength [级别]查看或设置检测强度
/ace toggle <检查> <on|off>开关某一项检测
/ace ops <on|off>OP 检测豁免开关（默认开）
/ace logs [数量]查看最近告警
/ace reload重载配置

每一项都能单独关掉

配置文件里每个检查都有自己的 enabled。 关掉是真的不检测 —— 连缓冲都不会累加， 也不会往危险等级上加分，不是"只不告警"。

比如只想关掉飞行检测： 

checks:
  fly:
    enabled: false      # 关掉飞行检测
    tolerance: 4
    risk: 4
    max-air-ticks: 40
  speed:
    enabled: true
    ...

游戏内也能改：/ace toggle Fly off，会写回配置文件并立刻生效。

  • /ace checks
    一次看全 22 项的开关状态
  • /ace toggle <检查> <on|off>
    单项开关，写回配置
  • 关掉就彻底不查
    不累加缓冲，不加危险等级
  • OP 默认豁免
    管理员测试不会被自己踢
QUICK START

三步用起来

装上就能跑，默认配置已是保守值

1️⃣

放下 jar 重启

把 LinuxACE-26.11.4.jar 放进 plugins/， 重启服务器。首次启动会自动生成 config.yml。

2️⃣

看状态

/ace status 确认强度、TPS、兼容插件识别情况， 顺便看看有没有哪项被自动关闭了。

3️⃣

等告警

有情况 OP 会收到可点击的告警。 建议先跑几天确认无误报，再考虑调高强度。
