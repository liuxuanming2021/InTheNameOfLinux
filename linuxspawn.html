4 类生物 · 每个世界单独设 · 0 ~ 1000 倍

WHAT

不自己刷怪，只让原版多跑几轮

Minecraft 1.12.2 的自然刷怪只有一个入口：WorldServer#doTick() 里调用 SpawnerCreature.a(...)，由 ticksPerMonsterSpawns / ticksPerAnimalSpawns 两个计数器决定「多久跑一次」。

LinuxSpawn 把这两个计数器置 0（原版调用直接 return），然后每 tick 自己调用同一个 SpawnerCreature.a(...)，倍率只决定「这一 tick 让原版循环跑几轮」。 位置、群系、光照、地表、世界边界、玩家距离、生物上限、CreatureSpawnEvent 全部还是原版代码在判断。

FEATURES

功能

三个开关就够：哪个世界、哪类生物、多少倍

🐺

四类生物分别设

怪物 / 动物 / 水生 / 环境分开调，倍率 0 = 该类完全不刷，1 = 原版，最大 1000。

🌍

每个世界单独生效

生存世界 2 倍、建筑世界 0 倍、末地完全不接管，一张 config.yml 就够。

🧹

自然怪物清理

只清未命名、未驯服、未拴绳、非刷怪笼产物的自然怪物；默认 10 分钟一次，分批处理不卡服。

🛡️

低 TPS 自动暂停

TPS 低于 safety.min-tps 时本 tick 不再补刷（世界仍被接管），恢复后自动继续。

📊

能证明倍率生效

/spawnrate stats 给出每秒原版循环数、每秒生成数、单轮耗时；App 里也能看。

📱

和 LinuxAPP 联动

原生 iOS 管理页新增「刷怪」页签：看 TPS 与实时曲线数据、按世界改倍率、一键分批清理。

COMMANDS

命令

命令 / 别名：/spawnrate · /sprate

命令说明
/spawnrate list列出所有世界的接管状态与倍率
/spawnrate stats每秒原版循环数、生成数、单轮耗时、TPS
/spawnrate set <世界> <类别> <倍率>改一个世界的一类倍率，立即生效并写回 config.yml
/spawnrate clean [世界|*] [类别|all] [半径|all] [dry]分批清理自然怪物；dry 只统计不删
/spawnrate reload重读 config.yml
COMPAT

和 InTheNameOfLinux 联动

26.11.18 起刷怪这块和 ITNOL 接上了，两件事：

审计

改倍率、清理、重载都会往 ITNOL 审计里写一条，和封禁、举报记在同一个文件。

2026-11-15 15:23:10   刷怪   控制台   world   倍率   怪物 → 1.5（LinuxSpawn）

APP 端改倍率时，操作人就是登录的那个账号。

权限

除了 spawnrate.admin，ITNOL 认定的协管（XlandCore 的 xlcore.mod）也能用这个命令。

/linux logs 的「子插件联动」里多一行：

LinuxSpawn  已加载 ✔  接管 3 个世界  TPS 19.7

和别的插件怎么相处

刷怪笼 / 领地

刷怪笼由 TileEntityMobSpawner 自己 tick，插件从不碰；领地插件在 CreatureSpawnEvent 里取消的生成，LinuxSpawn 照样照单全收。

假人 / 多世界

假人在原版玩家表里，所以有假人的地方照样刷怪；世界增删自动生效。

生物上限

mobcap、spawn-limits、mob-spawn-range 仍由服务端决定：倍率只提高「尝试次数」，到上限不会凭空变多。

LinuxAPP

服务端装 LinuxAPP 后，手机 App（iOS 13+ 原生）管理页多一个「刷怪」页签， 可以直接改倍率、看实时循环数、一键清理。

LinuxSpawn

位置和上限交还原版，只调频率。
