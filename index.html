REPORT SYSTEM

举报系统 NEW

玩家提交举报 → 管理层调查 → 处理并通知当事人

📝

提交流程

玩家提交举报后，插件会根据被举报人身份进行智能分流通知。

  1. 玩家提交/linux report <玩家> <原因>，1 分钟冷却
  2. 智能分流根据被举报人身份决定通知对象
  3. 24 小时冷却提交后 24 小时内不接受 / 驳回（调查期）
  4. 处理并通知接受或驳回，举报人收到结果
  5. 服主同步所有处理结果同步广播给服主
🎯

分流规则

根据被举报人身份，通知范围不同，避免打草惊蛇或漏报。

被举报人身份通知对象
服主仅服主本人
协管 / 管理员 / 副服主其他管理层（不含被举报人）
普通玩家所有管理层（不含举报人）
📢

离线消息缓存

服主离线时收到新举报 / 处理结果，消息自动缓存到 reports.yml。

  • 服主上线 10 秒后自动推送
  • 上限 100 条，超出丢弃最早的
  • 玩家离线期间的举报处理结果也会缓存
  • 玩家上线后延迟 3 秒推送
🧹

批量清理

支持多种清理模式，均需要二次确认。

/linux report clear handled # 已处理
/linux report clear all # 全部
/linux report clear pending # 待广播
/linux report clear player Steve
/linux report clear id 3
/linux report clear confirm # 确认执行
MODERATOR SYSTEM

协管权限体系

基于 XlandCore 身份，无 OP 也能高效管理

✅

协管可用

协管可以使用 8 个惩罚命令，覆盖功能封禁与解封，以及举报的查看 / 处理。

  • /linux banblock 禁用方块
  • /linux banmove 禁止移动
  • /linux banmsg 禁言
  • /linux banall 全面封禁
  • 以及 4 个对应的解封命令
  • /linux report list / info / accept / reject
⛔

协管不可用

账号封禁、隐身、重载、清空举报等命令仅限完整管理员。

  • /ban · /tempban · /banip
  • /unban · /unbanip
  • /hide
  • /linux reload
  • /linux report clear *
⏳

时长限制

协管封禁时长有上限，默认为 7 天，可在配置中调整。

  • 禁止永久封禁
  • 超过上限直接拒绝
  • 可提前解封
  • 解封命令无时间限制
🎨

界面分流

协管的帮助菜单和 TAB 补全只显示可用命令，界面清爽。

  • 帮助菜单：协管专用版
  • TAB 补全：仅显示可用命令
  • OP 优先：管理员显示完整版
  • XlandCore 未加载时回退权限节点
