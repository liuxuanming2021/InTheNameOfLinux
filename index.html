InTheNameOfLinux 综合管理

26.11.4正式版

服务器综合管理插件：身份验证、封禁体系、举报处理、协管权限、非法 NBT 检测、命令拦截与玩家保护。

  • PBKDF2 登录验证 · 聊天栏输密码零日志泄漏
  • 账号 / IP / 临时封禁 + 功能封禁（禁言、禁移动、禁交互）
  • 举报系统：提交 → 分流通知 → 处理并回执
  • 非法 NBT 检测（合并 BanNbt）：清除被改坏属性的物品
  • 命令拦截与玩家保护，可拦截针对保护对象的命令

LinuxTitle 头衔系统

26.11.2

头衔解锁与展示插件：28 个头衔，按游玩时长、统计数据、节日活动自动解锁，玩家可自由切换与关闭。

  • 28 个头衔：新人 / 常驻 / 元老 / PVP 之王 / 建筑大师 …
  • 按游玩时长、击杀数、挖掘数等条件自动解锁
  • 节日头衔：春节、端午、中秋、国庆自动开放
  • 每日活跃 / 硬核 / 传奇头衔，每天重新统计
  • 聊天前缀显示，支持 PlaceholderAPI 变量
查看介绍 使用帮助

FakePlayerPlugin 假人系统

26.11.2

假人插件：在服务器里放置不会掉线的"假玩家"，用于占位、挂机、撑活跃度，兼容 AuthMe。

  • 创建 / 移除假人，支持一次移除全部
  • 假人数据持久化，重启自动恢复
  • 区块强制加载，假人不会掉进虚空
  • 兼容 AuthMe，不会因为登录验证被踢
  • 支持按名字查询与列出所有假人
