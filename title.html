LinuxTitle

头衔解锁与展示插件 · 让玩家的付出看得见

查看功能 命令列表 综合帮助中心
FEATURES

核心功能

六大模块，覆盖头衔的解锁、展示与管理

🏅

28 个头衔

从「新人」到「传奇」，覆盖成长、技巧、社交与活动四大类。

  • 成长类：新人 / 常驻 / 元老
  • 技巧类：PVP 之王 / 建筑大师 / 矿工
  • 社交类：向导 / 守护者 / 赞助者
  • 活动类：节日头衔 + 每日头衔
⚙️

自动解锁

按条件自动判定，玩家无需申请，进服后自动检查。

  • 游玩时长达到门槛自动解锁
  • 统计数据（击杀 / 挖掘 / 死亡等）达标解锁
  • 管理员也可手动授予指定头衔
  • 默认每 60 秒复查一次
🎋

节日活动

内置农历换算，春节、端午、中秋自动按农历日期开放。

  • 春节 / 端午 / 中秋：农历自动换算
  • 元旦 / 国庆：公历日期区间
  • 节日期间自动解锁对应头衔
  • 持续天数可配置
📅

每日头衔

每天 0 点重置的活跃度头衔，鼓励玩家日常上线。

  • 每日活跃 / 每日硬核 / 每日传奇
  • 按当日在线时长判定
  • 重置时间可配置
  • 第二天重新统计，不会永久保留
💬

聊天前缀

解锁的头衔可显示在聊天前缀，玩家能自由切换或关闭。

  • 支持 PlaceholderAPI 变量
  • 玩家可 /title use 切换
  • 可 /title off 关闭显示
  • 权限节点分流：玩家命令 / 管理命令
🧭

新人引导

新玩家首次进服自动获得「新人」头衔。

  • 进服延迟 10 秒后自动授予
  • 超过指定游玩时长后不再授予
  • 避免老玩家重登被误判为新人
  • 头衔 ID 与阈值可配置

主命令 /title，别名 /titles、/lt

命令说明权限
/title help [页码]显示帮助菜单（按身份分流，可点击翻页）所有人
/title list [页码]列出全部头衔及自己的解锁状态所有人
/title use <头衔ID>使用 / 切换头衔所有人
/title off关闭头衔显示所有人
/title info <头衔ID>查看某个头衔的解锁条件与说明所有人
/title give <玩家> <头衔ID>手动授予玩家头衔linuxtitle.admin
/title revoke <玩家> <头衔ID>收回玩家头衔linuxtitle.admin
/title check [玩家]立即复查解锁条件linuxtitle.admin
/title reload重载插件配置linuxtitle.admin
