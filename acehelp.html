1快速开始

LinuxACE 是给服主用的低误报反作弊。它不追求"抓得狠"， 而是先保证不冤枉正常玩家：每次检测命中只累加缓冲， 连续命中够次数才算一次违规，缓冲每秒自动衰减。

三步上手

  1. 确认已安装 InTheNameOfLinux（硬依赖，缺它不启动）。
  2. 把 LinuxACE-26.11.4.jar 放进 plugins/ 并重启服务器。
  3. 执行 /ace 看主菜单，/ace status 看运行状态。
ℹ️
默认已经很保守 装上去先跑几天，用 /ace logs 确认没有误报，再考虑调高强度。

2命令详解

命令作用
/ace打开主菜单（面板，只显示重要信息）
/ace help [页码]完整命令帮助，可翻页、可点击
/ace status运行状态：强度、TPS、兼容插件、ITNOL 联动
/ace checks列出 22 项检测的开关、风险权重、容忍次数
/ace goto <玩家>变旁观者并传送过去（告警里的「点击前往」）
/ace back返回观察前的位置与游戏模式
/ace check <玩家>查看某人的危险等级与各检查命中次数
/ace lookup <玩家>调 InTheNameOfLinux 查询：封禁历史 + 反作弊记录
/ace ban <玩家> [理由]封禁（走 ITNOL 封禁体系）；不写理由时用触发的违规事件当理由
/ace exempt <玩家>临时豁免该玩家的检测
/ace reset <玩家>清零危险等级
/ace strength [级别]查看或设置检测强度（七档）
/ace toggle <检查> <on|off>开关某一项检测，关掉后完全不检测
/ace ops <on|off>OP 检测豁免开关
/ace logs [数量]查看最近告警
/ace reload重载配置
⚠️
只有管理员能用 /ace 要求 OP 或 linuxace.use 权限，普通玩家打不开。

4检测强度

一条命令切换松紧，不用改一堆数字：/ace strength <级别>

级别中文阈值倍率容忍倍率适用场景
Lowest最宽松×1.35×2.0误报几乎为零，明显作弊也会放过一部分
Low宽松×1.20×1.6客户端差异大、插件多的服务器
Medium中等×1.10×1.3比推荐值再松一点
Pro推荐×1.00×1.0默认值，抗误报优先
High严格×0.95×0.75开始能抓小动作，误报风险上升
Max很严格×0.90×0.60只建议无延迟、无特殊插件的纯净服
Highest最严格×0.85×0.45极易误报，仅测试或自建纯净服
💡
单项误报就调单项 把那一项的 tolerance 调大即可，比整体降强度精准得多。

5告警与处置

确认违规时向在线 OP 广播，告警是可点击的：

[LinuxACE]玩家 Steve 触发了 加速，等级 6 [点击前往]

鼠标移到告警上能看到现场信息：世界 · 坐标 · 延迟 · TPS · 危险等级。 点「点击前往」会变成旁观者并传送过去，/ace back 一键返回。

处置规则

  • 危险等级达到 20 → 踢出游戏，不封禁
  • 封禁只能由 OP 手动执行 /ace ban
  • 不写理由时，理由自动取触发的违规事件，形如 [LinuxACE]检测到 击退免疫
  • 封禁写入 InTheNameOfLinux，/linux lookup 能查到
  • 同一玩家同一检查有 10 秒告警冷却，不会刷屏

7配置与依赖

前置依赖

InTheNameOfLinux 是硬依赖：没装它、或它被禁用时，LinuxACE 不会启动。 封禁统一走它的封禁体系（记录 / 历史 / 审计 / 到期解封都由它管）； 反过来 ITNOL 可以单独运行，依赖是单向的。

关键配置

strength: Pro          # 检测强度
risk:
  kick-at: 20          # 危险等级达到多少踢出
  decay-seconds: 45    # 多少秒没新违规掉 1 点
  min-tps: 15.0        # TPS 低于此值暂停检测
exempt:
  ops: true            # OP 完全不检测
compat:
  auto-disable: true   # 检测到冲突插件时自动关闭对应检查
checks:
  fly:
    enabled: true      # 关掉就是真的不检测
    tolerance: 4
    risk: 4

插件兼容

  • KnockbackSync / CrazyEnchantments / XlandHighPvp / mcMMO → 自动关闭击退检查
  • MaxHealth / MMHp / mcMMO → 自动关闭回血检查
  • FakePlayerPlugin / ZNPCsPlus → 假人整体跳过
  • Slimefun → 手持自定义工具时不判秒挖
  • EaglerXServer / ViaVersion → 移动阈值额外放宽

所有放宽只在检测到对应插件时生效，没装就是最严格基线。

8常见问题

误报了怎么办？

  1. /ace check <玩家> 看是哪一项在报。
  2. 把那一项的 tolerance 调大（例如 3 → 6）。
  3. 整类都在报，再用 /ace strength 降一档。
  4. 确认是插件冲突，把冲突插件加进兼容判断。

为什么 OP 不会被检测？

默认开启了 OP 豁免（exempt.ops: true），避免管理员测试时被自己踢。 想验证检测是否生效，用 /ace ops off 临时关掉。

玩家会被自动封禁吗？

不会。LinuxACE 只会踢出，封禁必须由 OP 手动执行 /ace ban。

和 Vulcan / XlandAntiCheat 冲突吗？

不冲突。检测到还会在启动日志里提示，建议此时把对应检查设为只告警不踢，避免双重处罚。
