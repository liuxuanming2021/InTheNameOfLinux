WHY

为什么还得装一个 App

下面这些事，以前都只能进服、翻菜单、开控制台

💰

金币得进服才看得到

金币藏在服务器菜单的第几层，人在外面谁也说不清。 想知道自己攒了多少，只能上线翻一遍，或者找个在线的朋友帮你问。

🧾

点券和金币不在一个地方

金币一个菜单、点券另一个菜单，等级又在别的地方。 想对一下自己到底有多少家底，要点开四五层界面，还容易点错。

📈

经验看不到进度

升级差多少、总经验多少、现在这一级攒了几成 —— 游戏里只有一个会淡出的经验条， 想知道具体数字只能靠估算。

🚫

被封了不知道为什么

上线直接弹一行封禁提示，然后被踢出去。到期时间、封禁原因、是谁封的， 都得另外去群里问管理员。

💬

聊天、队伍、头衔全在游戏里

人不在游戏就插不上话；队伍要记一串命令；头衔得进菜单一层层翻， 还不知道差多少才解锁。

🛠

管理员封人要开控制台

人在外面遇到作弊的，得先连服务器、进控制台、敲命令，处理完再退出来。 手机上根本没法做这件事。

FEATURES

装上都有些什么

一个人一屏数据，管理员多一个能动手的页面

📊

我的数据

登录后第一屏就是自己的数据，一屏看完，不用点来点去。 离线也能看 —— 只要服务器开着插件，数据就在。

  • 顶部一行在线 / 离线状态，跟着服务器实时变
  • 金币、点券、等级三张大卡，数字用大字号，扫一眼就够
  • 队伍、头衔、累计在线时长、最近一次上线时间都在下面
🃏

三张数据卡

金币、点券、等级各占一张卡，几千几万自动缩写成「1.2 万」， 不会一屏塞满零。

  • 没装对应的经济插件，那一张卡显示 「—」 而不是 0
  • 数字太长自动缩写，点一下能展开看完整数值
  • 下拉即刷新，不用等自动刷新那一轮
📶

经验进度条

当前等级到下一级的进度条，旁边标着 1200 / 2400 exp 这种具体数字。

  • 总经验单独一行，不掉级就只增不减
  • 进度按实时经验算，杀一只怪就能看到条往前走
🤝

队伍与头衔

联动 LinuxTeam 和 LinuxTitle， 队伍名带方括号，头衔单独一行。

  • 没队伍显示「无队伍」，不会空一块
  • 服务器改了队伍名，App 下一次刷新就跟上
🔨

玩家管理页

名单里的人（或者 OP）会多出一个管理页：搜人 → 点选 → 填原因 → 选时长 → 封禁， 解封同样点两下。

  • 按名字模糊搜，最多列 20 条
  • 封禁立刻生效，在线的人当场被踢
  • 每次操作都写审计日志，事后查得到
📅

每日签到

进 App 点一下就有奖励：50% 概率 5000 金币，剩下的给 1–5 点券。 每天 0 点（北京时间）重置。

  • 连续签到天数、累计天数都记着
  • 断一天，连签从 1 重新算，累计不清零
  • 当天签过按钮变「已签到」，点不动
🚨

举报 · 惩罚 · 假人

管理页里四个子标签：玩家 / 举报 / 惩罚 / 假人。 玩家搜得到在线和离线的，点进去能封禁、禁言、移动封禁、方块封禁。

  • 举报列表能看到谁举报谁、理由、处理结果
  • 惩罚按类型分开解除，不用去记 /unban 的写法
  • 假人列表带坐标与在线状态，能直接移除
🌓

浅色 · 深色 · 三种风格

默认浅色，晚上切深色。风格能挑「默认 / Miuix / iOS」——Miuix 是大圆角无边框那一套， iOS 是半透明液态玻璃 + 毛玻璃顶栏；再配六种强调色，改完立刻生效。

  • 不跟着系统走，自己说了算
  • iOS 风格可开悬浮导航：底栏变成浮起来的一颗胶囊
  • 切完立刻生效，不用重启 App
🔐

安全是怎么做的

App 说到底是个能读你数据的入口，所以密码这件事一步都没省： 密码不存本地、不存服务端，登录时交给 AuthMe 校验完就丢； 之后发的是签名令牌，限定时间、限定次数。

  • 密码走 AuthMe 校验，插件自己不存、不写日志
  • HMAC 签名令牌，默认 7 天过期
  • 改一次 token.secret，所有令牌立刻作废
  • 每个 IP 每分钟 5 次登录、180 次请求
  • 默认公网直连（明文 HTTP）；想加密可挂 Nginx 或开插件自带 TLS
  • 封禁、解封都进 audit.log

第一次打开要填接口地址

App 不认服务器名字，只认一个地址。填 Nalxer 服务器的接口域名就行， 后面所有数据都从这个地址取：

接口地址： https://api.nalxer.top # 不要带 /api，也不要在结尾加斜杠
账号： 游戏 ID（就是你进服用的那个名字）
密码： 游戏密码（AuthMe 那个密码，不是邮箱密码）
⚠
「未知来源应用」不是中毒 APK 没有经过应用商店签名，安卓默认会拦一下。去系统设置里给浏览器（或文件管理器）打开「安装未知应用」权限， 再点一次安装就可以了。装完这个权限可以关回去。
ℹ️
地址两种写法都行 App 里的地址随便改：直连就填 http://服务器IP:49282，挂了 Nginx 就填 https://api.nalxer.top，设置页还有「测试连接」按钮能当场验证。 安卓 9 以后默认禁止明文 HTTP，填 http 打不开的话就在 App 里换成 https 域名。
SETUP

服务器这边三步

放插件、反代一个域名、手机登录，就这些

①

放插件，重启

把 NalxerApp.jar 丢进 plugins/，重启服务器， 启动日志会打 6 行 [联动]，告诉你接上了哪些插件。

plugins/
└── NalxerApp.jar
②

Nginx 反代一个域名

想走域名 + HTTPS 的时候，Nginx 转一层： api.nalxer.top → 127.0.0.1:49282。

location /api/ {
proxy_pass http://127.0.0.1:49282;
proxy_set_header X-Real-IP $remote_addr;
}
③

手机装 APK 登录

装上安卓版，第一屏填接口地址，再用游戏 ID + 游戏密码登录， 数据立刻就能看到。

https://api.nalxer.top
游戏 ID + 游戏密码
ℹ️
没有域名也能先用 在服务器上 curl http://127.0.0.1:49282/api/health 可以看接口活没活；手机浏览器打开 http://服务器IP:49282/api/health 能看到同样的 JSON，就说明安全组也通了。 但手机要连，还是得有一个 https 域名 —— 这是故意设计的，不是懒得写。 完整的 server 块写在 帮助页的 Nginx 一节。
