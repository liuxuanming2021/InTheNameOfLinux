────────────────────────────────────────────────────────────────────
一、你是什么身份？先自检
────────────────────────────────────────────────────────────────────
在游戏里输入：

    /linux help

标题显示「管理员帮助」= 你是管理员档。
显示「协管帮助」= 你被当成协管（权限较低）；显示「玩家帮助」= 管理权限没配好。

也可以直接自检：

    /linux checkop       检查自己的身份与管理权限
    /linux checkop list  列出所有管理员

────────────────────────────────────────────────────────────────────
三、你能做什么（完整清单）
────────────────────────────────────────────────────────────────────

■ 1. 账号封禁
    /ban <玩家> [原因]                  永久封禁账号
    /linux ban <玩家> [原因]            同上（两者等价）
    /tempban <玩家> <时间> [原因]       临时封禁，到期自动解封
    /banip <玩家/IP> [原因]             封禁 IP（同 IP 玩家会被踢出）
    /unban <玩家>                       解封玩家（并删除最近一条历史）
    /unbanip <IP>                       解封 IP
    /xlban <玩家> [原因]                永久封禁的别名
    /banlist [页码]                     查看封禁列表（可点击翻页）

■ 2. 功能封禁（和协管相同）
    /linux banblock <玩家> [时间] [原因]     禁用方块交互
    /linux unbanblock <玩家>                 解除
    /linux banmove <玩家> [时间] [原因]      禁止移动
    /linux unbanmove <玩家>                  解除
    /linux banmsg <玩家> [时间] [原因]       禁言
    /linux unbanmsg <玩家>                   解除
    /linux banall <玩家> [时间] [原因]       三合一
    /linux unbanall <玩家>                   解除全部

    ★ 注意：功能封禁的时间**可以不写**（= 永久），
      但你作为管理员同样可以永久；协管则强制要求填时间且 ≤ 7 天。

■ 3. 查询与记录
    /linux lookup <玩家/IP>          查 UUID、IP、身份、游玩时长、所在维度坐标、封禁历史
    /linux seenip <IP>               查用过该 IP 的所有玩家
    /linux history <玩家>            查看完整封禁历史
    /linux clearhistory <玩家>       清除历史（需二次确认）

■ 4. 举报处理
    /linux report <玩家> <原因>        提交举报（1 分钟冷却）
    /linux report list                查看待处理举报
    /linux report info <ID>           查看详情
    /linux report accept <ID> [备注]   接受
    /linux report reject <ID> [备注]   驳回
    /linux report clear handled       清空已处理（需确认）
    /linux report clear all           清空全部（需确认）
    /linux report clear pending       清空待广播（需确认）
    /linux report clear player <玩家>  清空某玩家相关（需确认）
    /linux report clear id <ID>       删除指定（需确认）
    ★ 清空类命令执行后会要求再发一次 confirm 才真正执行（5 分钟有效）。

■ 5. 运维与状态
    /linux logs [页码]              插件状态总览（开关、数据文件、定时任务、子插件联动）
    /linux audit [玩家] [页码]       审计日志：谁在什么时候改了什么
    /linux reload                   重载配置文件（会回报配置校验结果）
    /linux plugins                  插件联动状态（一屏看完）
    /linux fp                       假人插件状态
    /linux fp list                  列出所有假人
    /linux fpsync                   手动同步假人数据

────────────────────────────────────────────────────────────────────
四、封禁操作要点
────────────────────────────────────────────────────────────────────

【1】时间格式

    /tempban Steve 1d12h 刷屏       1 天 12 小时
    /tempban Steve 600 刷屏         只写数字 = 600 秒
    /tempban Steve 7d 多次违规      7 天

    单位：s 秒 / m 分 / h 时 / d 天 / w 周，可组合。

    不写时间 = 永久（对 /ban 而言本来就是永久；
    /tempban 不写时间按永久处理，请谨慎）。

【2】非法时间会被拒绝，不会变成永久
    /tempban Steve 0 原因       → 报错中止
    /tempban Steve abc 原因     → 报错中止
    /tempban Steve 99999999999999999999h → 报错中止
    （旧版本这些会被静默当成永久封禁，现已修复）

【3】解封会同时删掉最近一条历史
    /unban Steve     → 解封 + 删除 Steve 最近的一条封禁记录
    /unbanip 1.2.3.4 → 同理

【4】临时封禁到期
    到期自动解封，并在到期前全服提醒（默认提前 60 秒）。
    服务器重启后提醒任务会自动重建，不会丢。

【5】玩家名不区分大小写
    /ban steve、/ban Steve、/ban STEVE 效果完全相同，
    提示里统一显示真实名字 Steve。
    查询不存在的名字会明确提示「玩家 X 从未游玩」，
    不会像旧版本那样给出一个凭空的假 UUID。

────────────────────────────────────────────────────────────────────
七、重要机制（避免误操作）
────────────────────────────────────────────────────────────────────

【1】写命令提到 fs1 会被拦截
    服务器上有另一个插件（x1 / FastMenu.jar）的保护对象叫 fs1。
    本插件接管了这份保护：
        · 任何**提到 fs1** 的命令都会被拦下，并同时通知 fs1 与服主
        · 但 fs1 本人与服主不受限
    表现：你执行 /ban fs1 会收到
        玩家 你 尝试对 fs1 使用命令 /ban fs1 已拦截！
    这不是 bug，是保护机制。确实需要处理 fs1 请找服主。

【2】非法 NBT 检测会周期性扫描
    默认每 20 秒扫一次全体在线玩家，发现被改坏属性的物品（超限附魔、
    非法攻击力/生命/护甲等）会**直接清除**并播报给服主。
    ★ 注意：**op 不豁免** —— 管理员自己拿着这类物品一样会被清掉。
    如果你的测试物品被清了，属于正常行为。

【3】你的所有操作都有审计记录
    封禁、解封、功能封禁、举报处理、配置修改都会被记录。
    服主可随时 /linux audit 你的名字 查询。请按规则使用权限。

────────────────────────────────────────────────────────────────────
八、常见问题
────────────────────────────────────────────────────────────────────

Q：/ban 提示"没有权限"？
A：你的权限节点没配好。需要 inthenameoflinux.ban。
   如果是协管身份，本来就没有这个权限，需要封号请找管理员或服主。

Q：提示"玩家 X 从未游玩"？
A：这个名字在服务器记录里不存在（可能打错字）。
   本插件只认配置文件里真实存在过的玩家名，不会凭空造数据。

Q：封了但玩家还能进？
A：可能是 IP 没封住（玩家换 IP）。用 /linux seenip 查同 IP 的其他账号，
   再 /banip 一并封禁。

Q：功能封禁没生效？
A：确认命令提示是「已禁言 xxx」而不是「记录功能封禁失败」。
   后者说明写盘失败，惩罚未生效，请通知服主检查磁盘。

Q：想解除某个玩家的所有惩罚？
A：/linux unbanall Steve（功能封禁）
   /unban Steve          （账号封禁）
   两者是独立的，需要分别解除。

────────────────────────────────────────────────────────────────────
附：到期自动解除 vs 手动解除（记录处理不同）
────────────────────────────────────────────────────────────────────
【自动到期】临时封禁 / 功能封禁的时间到了，系统自动解除：
    · **封禁记录会保留**，并标记解除时间
    · 可用 /linux history <玩家> 或 /linux lookup <玩家> 查到
      显示形如：过期: 2026-10-10 20:29:29 [已解除 2026-10-10 20:29:30]
    · 玩家**不再受限**，/banlist 也不会把它列为生效中的封禁

【手动解除】/unban、/unbanip、/linux unbanmsg、/linux unbanall 等：
    · **会删除记录**（视为误封或提前解封）

    ★ 也就是说：想彻底抹掉一条封禁痕迹，用手动解除命令；
      自动到期只是"解除限制"，履历会留着供追溯。
