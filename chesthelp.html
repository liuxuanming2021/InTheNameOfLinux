1快速开始

LinuxChestGUI 是 ITNOL 的箱子 GUI 管理面板。 所有操作直接作用在 ITNOL 上，效果等于在聊天栏敲命令。

三种打开方式

  1. 命令 /lchest（别名 /chest、/lcgui、/book）
  2. 命令 /lchest give 领一本「Linux插件系统」附魔书
  3. 右键那本书，随时打开
ℹ️
硬依赖 ITNOL 没有 InTheNameOfLinux 就不会加载；权限：linuxchest.use / linuxchest.admin。

2页面说明

页面作用权限
主页功能入口 + 状态摘要所有人
运行状态在线 / TPS 实时 / 内存 / 封禁数所有人
插件联动8 个 Linux 系插件加载状态所有人
我的信息名字 / 身份 / 世界 / 坐标 / 生命所有人
封禁管理在线 + 离线玩家列表管理员
玩家操作封禁 / 三项处罚 / 解除 / 踢出管理员
举报处理左键受理 右键驳回管理员
封禁列表生效封禁，点击可解封管理员

3封禁与处罚

三步流程

  1. 选操作 —— 封禁 / 禁言 / 禁移动 / 禁交互，四项平级
  2. 选时长 —— 1 小时 / 1 天 / 7 天 / 30 天 / 10 年 / 永久
  3. 选理由 —— 点一下选中，再点「确认执行」

理由清单（取自服务器规则）

档位理由
轻度 1-7 天盗窃其他玩家物品 · 一直击杀其他玩家 · 损坏主城周围地形
中度 7-30 天毁坏玩家建筑 · 毁坏公共建筑 · 使用 TNT 毁坏地形 · 持有违规道具（32k）· 大量刷物品/刷货币 · 破坏他人领地 · 使用作弊客户端
重度 30 天-永久攻击服务器（压测/发包）· 制造卡服机/禁人塔 · 盗取 OP 权限/盗号
其它其他（手动输入）

手动输入的理由

选「其他（手动输入）」后关界面，到聊天栏写一句话就是理由。

⚠️
5 分钟超时 超过 5 分钟再输入，本次操作自动作废，需要重新走一遍流程。

离线玩家

玩家列表 = 在线玩家 + 从 data.yml、playtime.yml 读到的离线玩家，同样可以封禁、处罚。

4举报处理

「举报处理」页列出所有待处理举报：

  • 左键 → 受理
  • 右键 → 驳回
  • 处理完自动刷新列表

显示内容：举报编号、举报人、被举报人、理由。

5导航与手机优化

设计原因
只围外圈玻璃板内部留空，不误触空槽
理由两行各 7 个铺满不留洞，视觉整齐
返回一律回上一级层级清晰，不会一下跳回主页
底部固定返回 / 关闭位置永远不变
列表自动分页玩家多也不会挤爆
ℹ️
返回层级 理由页 → 时长页 → 玩家操作页 → 玩家列表 → 主页，一层层退。
